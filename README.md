# 💻 Programación - Inicio Java & AI

**¡Realme es chulísimo y súper original!** 😎 Este repositorio recoge todos mis primeros pasos en programación, centrados en **Java** y conceptos básicos de **Inteligencia Artificial**. Aquí aprenderás desde variables y arrays hasta mini-proyectos con lógica y algoritmos sencillos.

---

## 📚 Contenido del repositorio

1️⃣ **Variables y Tipos de Datos**  
- Variables primitivas y objetos  
- Conversión de tipos  
- Identidades y constantes  

2️⃣ **Arrays**  
- Arrays unidimensionales  
- Arrays multidimensionales  
- Manipulación básica con bucles  

3️⃣ **Funciones / Métodos**  
- Declaración y uso de métodos  
- Parámetros y retorno de valores  
- Funciones recursivas básicas  

4️⃣ **Mini-proyectos y ejercicios**  
- Problemas aplicando arrays y funciones  
- Ejercicios resueltos paso a paso  
- Mini-IA: pequeños algoritmos de lógica o cálculo  

---

## 🌟 Objetivo

El objetivo de este repositorio es **aprender y mostrar de forma práctica cómo funciona la programación en Java**, desde conceptos básicos hasta algoritmos sencillos de IA, todo explicado con ejemplos que se puedan probar y modificar fácilmente.
